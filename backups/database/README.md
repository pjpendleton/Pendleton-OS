# Encrypted database artifacts only

**There is no live-data backup in this folder yet.**

This repository is PUBLIC. Plaintext database backups, connection strings,
tokens, credentials, private encryption keys and SQL data dumps must not be
committed here. Store only encrypted `*.tar.age` files and checksums.

See [Database backup and retirement](../../docs/DATABASE-BACKUP-AND-RETIREMENT.md)
for the export, verification, and recovery requirements.
